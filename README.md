# One Emoji, One Smile

One emoji, the one most likely to make a stranger smile.

## The entry

`main.ts` (Node 22, standard library only) writes exactly one emoji to
`/output/entry.txt`:

🫶 — heart hands. A small, warm, deliberate gesture of kindness: the kind
of thing a stranger reads at a glance as friendly, with no context needed,
no irony, and nothing intimate. Chosen rather than the first smiley that
comes to mind, while staying instantly readable by anyone, of any age.

## Run

```sh
node main.ts
```

It writes the emoji to `/output/entry.txt` (UTF-8, one character) and
re-reads the file to check the gate: 1–8 characters, not only whitespace.
